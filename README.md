# Prospecta V2.4

Atualização do Prospecta com indicadores financeiros mensais no Dashboard, mantendo os recursos da V2.3.

## Novidades da V2.4

- **Faturamento do mês**: soma dos valores dos leads fechados no mês atual.
- **Ticket médio**: faturamento mensal dividido pela quantidade de vendas fechadas no mês.
- **Vendas fechadas**: quantidade de leads que passaram para status **Fechado** no mês atual.
- **Projeção mensal**: estima o faturamento do fim do mês usando o ritmo atual. A fórmula é faturamento acumulado / dias corridos × total de dias do mês.
- Os indicadores usam os campos **Valor fechado (R$)** e **Data do fechamento** já existentes.

## Recursos mantidos da V2.3

- Botão Google Maps na aba Leads.
- Meta semanal configurável em Configurações.
- Dashboard com faturamento semanal, valor faltante e barra de progresso.
- Backup JSON com configurações.
- Exportação CSV com valor e data de fechamento.
- Assistente IA por fluxo manual com ChatGPT.

## Observação sobre a projeção

A projeção é apenas uma estimativa matemática baseada no ritmo do mês até o dia atual. Ela não garante o faturamento futuro.
